## 라우팅 프로토콜 (RIP, OSPF, BGP)

### 핵심 개념
라우팅 프로토콜은 패킷이 목적지까지 이동할 최적 경로를 결정하는 프로토콜이다. 크게 내부 게이트웨이 프로토콜(IGP: RIP, OSPF)과 외부 게이트웨이 프로토콜(EGP: BGP)로 나뉜다. RIP는 홉 수(Hop Count) 기반 거리 벡터 방식, OSPF는 링크 상태 방식으로 다익스트라 알고리즘을 사용, BGP는 AS(자율 시스템) 간 경로를 교환하는 경로 벡터 방식이다.

### 키워드

| 구분 | RIP | OSPF | BGP |
|------|-----|------|-----|
| **알고리즘** | 거리 벡터(Bellman-Ford) | 링크 상태(Dijkstra) | 경로 벡터 |
| **메트릭** | 홉 수(Hop Count) | 대역폭(Cost) | 정책(Policy) |
| **최대 홉** | 15홉 (16 = 무한) | 제한 없음 | 제한 없음 |
| **적용 범위** | IGP (소규모 내부망) | IGP (대규모 내부망) | EGP (AS 간, 인터넷) |
| **업데이트** | 주기적 전체 전송 | 변경 시만 전송(LSA) | 변경 시만 전송 |
| **수렴 속도** | 느림 | 빠름 | 보통 |
| **표준** | RFC 1058 | RFC 2328 | RFC 4271 |

### 기출 계산 예시

**2024-2회 기출**: 경로 A→D→C→F 계산
- RIP 기준 홉 수로 최단 경로 선택
- A→B: 1홉, A→D: 1홉 → D→C: 1홉, D→F: 1홉
- A→D→C→F = 3홉 vs A→B→C→F = 3홉 (동일 시 알파벳 순)
- 결과: RIP는 홉 수가 동일하면 첫 번째로 발견된 경로 선택

### 기출 포인트
> **2024-2회**: RIP 최단 경로 계산 A→D→C→F 직접 출제 — 홉 수 기반 계산
> **핵심 구분**: RIP=거리벡터(홉수)/OSPF=링크상태(다익스트라)/BGP=경로벡터(AS간)
> **RIP 한계**: 최대 15홉 제한 → 대규모망 불가, 수렴 속도 느림(라우팅 루프 가능)
> **OSPF 특징**: 링크 변경 시 LSA(Link State Advertisement)만 전송해 효율적
> **BGP 역할**: 인터넷 AS 간 라우팅 → KT, SK브로드밴드 등 ISP 간 경로 교환

### 연결 개념
- 관련 카드: `nw-subnet-001` (서브넷팅 — 라우팅 경로 계산의 기반)
- 관련 카드: `nw-protocol-004` (네트워크 장비 — 라우터의 역할)
