## C언어 진수 변환과 비트 연산

### 핵심 개념
컴퓨터는 2진수로 데이터를 처리하며, 프로그래밍에서는 10진수, 2진수, 8진수, 16진수 간 변환이 빈번하다. C언어의 비트 연산자는 비트 단위로 데이터를 조작하며, 진수 변환 코드와 비트 연산 결과 추적이 기출파괴 포인트로 등장했다.

### 키워드
- **printf 서식**: `%d`(10진수), `%o`(8진수), `%x/%X`(16진수)
- **0x 접두어**: 16진수 리터럴. `0x1A` = 26
- **0 접두어**: 8진수 리터럴. `010` = 8
- **비트 AND(&)**: 두 비트 모두 1이면 1
- **비트 OR(|)**: 하나라도 1이면 1
- **비트 XOR(^)**: 서로 다르면 1
- **비트 NOT(~)**: 비트 반전
- **왼쪽 시프트(<<)**: 비트를 왼쪽으로 이동. `n << 1` = n × 2
- **오른쪽 시프트(>>)**: 비트를 오른쪽으로 이동. `n >> 1` = n / 2

### 진수 변환 방법
```
10진수 87 → 16진수:
87 ÷ 16 = 5 ... 나머지 7  → hex[0] = '7'
 5 ÷ 16 = 0 ... 나머지 5  → hex[1] = '5'
역순 출력 → 57

10진수 26 → 2진수:
26 ÷ 2 = 13 ... 0
13 ÷ 2 = 6  ... 1
 6 ÷ 2 = 3  ... 0
 3 ÷ 2 = 1  ... 1
 1 ÷ 2 = 0  ... 1
역순 → 11010
```

### printf 서식 출력
```c
int n = 255;
printf("%d\n", n);    // 255
printf("%o\n", n);    // 377
printf("%X\n", n);    // FF
printf("%x\n", n);    // ff
```

### 비트 연산 예시
```c
int a = 0x1A;  // 26 = 0001 1010
int b = 0x0F;  // 15 = 0000 1111
printf("%X\n", a & b);  // 0A (AND: 0000 1010)
printf("%X\n", a | b);  // 1F (OR:  0001 1111)
printf("%X\n", a ^ b);  // 15 (XOR: 0001 0101)

int c = 3;        // 0000 0011
printf("%d\n", c << 2);  // 12 (0000 1100) — 3 × 4
printf("%d\n", c >> 1);  // 1  (0000 0001) — 3 / 2
```

### 기출 포인트
> - **2025-1회**: 10진수 → 16진수 변환 코드 출력 추적 (답: 908). **기출파괴 포인트**로 수험생 다수 오답
> - **출제 패턴**: while문으로 나머지 연산 반복 → 역순 출력. 진수 변환 원리를 코드로 구현
> - **비트 연산**: AND/OR/XOR/시프트 연산 결과 추적. 2진수로 변환 후 비트별 계산
> - **주의**: `%X`는 대문자, `%x`는 소문자 16진수 출력
