# 정보처리기사 실기 출제 트렌드 조사 (2024–2026)

조사일: 2026-03-28
대상 과목: 소프트웨어 설계(SE), 데이터베이스(DB)

---

## 전체 시험 흐름 요약

| 연도/회차 | 특징 | 합격률 |
|-----------|------|--------|
| 2024년 1회 | C/Java/Python 코딩 8문항. 이론 난이도 보통 | - |
| 2024년 2회 | 프로그래밍 문제 비중 증가, 난이도 상승 | - |
| 2024년 3회 | 이론 쉬움, 코딩 극악 난이도 | 20.71% |
| 2025년 1회 | 자료구조 대거 등장 → 합격률 급락. 디자인패턴·UML·결합도/응집도 출제 | - |
| 2025년 3회 | 초고난도 프로그래밍 + 기출 외 SQL 문제 출제 → 대거 탈락 유도 | 24% |

**핵심 트렌드**: 이론은 안정적이나 코딩·SQL 난이도 지속 상승. 기출 밖 SQL 출제 사례 등장으로 단순 암기 외 응용력 필요.

### SE-1. UML 다이어그램

```
주제: UML 다이어그램 (클래스·시퀀스·유스케이스)
과목: SE
출제 빈도: 매회
최근 출제 회차: 2024-1회, 2024-2회, 2025-1회
핵심 키워드: 클래스다이어그램, 시퀀스다이어그램, 유스케이스다이어그램, 구조다이어그램, 행위다이어그램, 관계표기법, 영문명칭
카드화 우선순위: 상
```

**비고**: CBT 전환 이후 영문 표기(Class Diagram, Sequence Diagram 등)도 함께 출제. 관계 표기(연관·집합·합성·의존·실체화·일반화)와 다이어그램 해석 문제 자주 나옴.

## 데이터베이스 (DB) 출제 트렌드

### DB-1. SQL (DML - SELECT 중심)

```
주제: SQL DML (SELECT, INSERT, UPDATE, DELETE)
과목: DB
출제 빈도: 매회
최근 출제 회차: 2024-1회, 2024-2회, 2024-3회, 2025-1회, 2025-3회
핵심 키워드: SELECT, WHERE, JOIN(INNER/OUTER/CROSS), GROUP BY, HAVING, ORDER BY, DISTINCT, 서브쿼리, 집계함수(COUNT/SUM/AVG/MAX/MIN)
카드화 우선순위: 상
```

**비고**: 3~4문제씩 출제. 2025년 3회 기출 외 SQL 출제로 난이도 급상승. DISTINCT 페이크 문제(결과 행 수 계산) 반복 출제.

---

### DB-2. SQL 분류 (DDL/DML/DCL/TCL)

```
주제: SQL 명령어 분류 (DDL, DML, DCL, TCL)
과목: DB
출제 빈도: 매회
최근 출제 회차: 2024-1회, 2025-1회
핵심 키워드: CREATE, ALTER, DROP, TRUNCATE, SELECT, INSERT, UPDATE, DELETE, GRANT, REVOKE, COMMIT, ROLLBACK, SAVEPOINT
카드화 우선순위: 상
```

**비고**: 4가지 분류와 각 명령어 매칭이 정형화된 출제 유형. TRUNCATE가 DDL(AUTO COMMIT)임을 헷갈리는 수험생 많음.

---

### DB-3. 정규화 / 반정규화

```
주제: 정규화 (1NF~BCNF) 및 반정규화
과목: DB
출제 빈도: 매회
최근 출제 회차: 2024-1회, 2024-2회, 2024-3회
핵심 키워드: 1NF, 2NF, 3NF, BCNF, 함수종속, 부분함수종속, 이행함수종속, 결정자, 반정규화, 이상현상(삽입/삭제/갱신)
카드화 우선순위: 상
```

**비고**: 함수 종속 다이어그램에서 정규형 단계 판별 문제 자주 출제. 이상현상 3가지도 단골 서술 문제.

---

### DB-4. 트랜잭션 / ACID

```
주제: 트랜잭션 개념 및 ACID 특성
과목: DB
출제 빈도: 자주
최근 출제 회차: 2024-1회, 2024-3회, 2025-1회
핵심 키워드: 원자성(Atomicity), 일관성(Consistency), 격리성(Isolation), 영속성(Durability), COMMIT, ROLLBACK, 병행제어, 직렬화, 로킹
카드화 우선순위: 상
```

**비고**: ACID 4가지 영문명+한글명+정의 3세트 암기 필수. 병행제어 문제(로킹·타임스탬프)도 일부 출제.

---

카드화 우선순위: 상
