포인터 재귀함수 구조체 비트연산 매크로

포인터와 배열

*(arr+i)와 arr[i]는 동일, &arr[i]는 주소

포인터와 문자열

char *str로 문자열 접근, 널 문자(\0) 종료

구조체 struct

사용자 정의 자료형, 멤버 접근 연산자(. , ->)

재귀함수

자기 자신을 호출, 종료 조건 필수, 스택 추적

비트 연산

&(AND), |(OR), ^(XOR), <<(좌시프트), >>(우시프트)

printf 서식

%d, %f, %c, %s, %o, %x, %-10d 등 서식 지정자

#define 매크로

선행처리기 텍스트 치환, 괄호 주의

2차원 배열

arr[i][j] = *(*(arr+i)+j), 행 우선 저장

switch-case

break 없으면 fall-through, default 처리

call by value/reference

값 전달 vs 주소 전달(포인터), 원본 변경 여부

문제 1
포인터와 배열 ★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;

    printf("%d\n", *p);
    printf("%d\n", *(p + 2));
    printf("%d\n", *p + 2);
    p += 3;
    printf("%d\n", *p);
    printf("%d\n", p[-1]);

    return 0;
}
정답 및 해설 보기
10
30
12
40
30
핵심: 포인터 산술과 역참조 연산자 우선순위를 구분하세요.
• *p → arr[0] = 10
• *(p+2) → arr[2] = 30 (포인터를 2칸 이동 후 역참조)
• *p+2 → arr[0]+2 = 10+2 = 12 (*가 +보다 우선순위 높음)
• p+=3 후 *p → arr[3] = 40
• p[-1] → *(p-1) → arr[2] = 30
*(p+2)와 *p+2는 완전히 다른 결과! 괄호 위치에 주의하세요.
문제 2
포인터와 문자열 ★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    char *str = "HELLO";
    int count = 0;

    while (*str != '\0') {
        if (*str == 'L')
            count++;
        str++;
    }
    printf("%d\n", count);

    char *a = "ABCDEF";
    printf("%c\n", *(a + 3));
    printf("%s\n", a + 2);

    return 0;
}
정답 및 해설 보기
2
D
CDEF
핵심: 문자열은 char 배열이며, 포인터로 각 문자에 접근합니다.
• "HELLO"에서 'L'은 인덱스 2, 3에 위치 → count = 2
• *(a+3) → 'D' (%c로 문자 출력)
• a+2 → "CDEF" (%s로 해당 주소부터 \0까지 출력)
%c는 한 문자, %s는 해당 주소부터 널 문자까지 전체 문자열을 출력합니다.
문제 3
구조체 struct ★★☆

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

struct Student {
    char name[20];
    int score;
};

void addBonus(struct Student *s, int bonus) {
    s->score += bonus;
}

int main() {
    struct Student st = {"Kim", 85};

    printf("%s %d\n", st.name, st.score);
    addBonus(&st, 10);
    printf("%s %d\n", st.name, st.score);

    struct Student *p = &st;
    p->score = 100;
    printf("%d\n", st.score);

    return 0;
}
정답 및 해설 보기
Kim 85
Kim 95
100
핵심: 구조체 포인터는 ->로 멤버에 접근하며, 주소를 전달하면 원본이 변경됩니다.
• 초기값: name="Kim", score=85
• addBonus(&st, 10) → 포인터로 전달하여 score = 85+10 = 95
• p->score = 100 → 포인터로 직접 변경 → st.score = 100
구조체를 값으로 전달하면 복사본이 변경되고, 포인터로 전달해야 원본이 변경됩니다.
문제 4
재귀함수 추적 ★★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

void func(int n) {
    if (n <= 0)
        return;
    func(n - 1);
    printf("%d ", n);
    func(n - 2);
}

int main() {
    func(4);
    printf("\n");
    return 0;
}
정답 및 해설 보기
1 2 1 3 1 4 1 2 1
핵심: 이진 재귀 호출은 트리 구조로 추적합니다.
• func(4): func(3) → print 4 → func(2)
• func(3): func(2) → print 3 → func(1)
• func(2): func(1) → print 2 → func(0)
• func(1): func(0) → print 1 → func(-1)
• 전체 순서: 1 2 1 3 1 4 1 2 1
재귀 호출이 printf 앞뒤로 있으면 출력 순서가 복잡해집니다. 트리를 그려서 추적하세요.
문제 5
비트 연산 ★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    int a = 12;  // 1100
    int b = 10;  // 1010

    printf("%d\n", a & b);
    printf("%d\n", a | b);
    printf("%d\n", a ^ b);
    printf("%d\n", a << 1);
    printf("%d\n", b >> 1);

    return 0;
}
정답 및 해설 보기
8
14
6
24
5
핵심: 2진수로 변환하여 비트 단위 연산을 수행합니다.
• a=12(1100), b=10(1010)
• a & b → 1100 & 1010 = 1000 = 8 (AND: 둘 다 1이면 1)
• a | b → 1100 | 1010 = 1110 = 14 (OR: 하나라도 1이면 1)
• a ^ b → 1100 ^ 1010 = 0110 = 6 (XOR: 서로 다르면 1)
• a << 1 → 11000 = 24 (좌시프트: ×2 효과)
• b >> 1 → 0101 = 5 (우시프트: ÷2 효과)
문제 6
printf 서식 지정자 ★★☆

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    int a = 65;
    float b = 3.14159;

    printf("%d\n", a);
    printf("%c\n", a);
    printf("%o\n", a);
    printf("%x\n", a);
    printf("%.2f\n", b);
    printf("%10.1f\n", b);

    return 0;
}
정답 및 해설 보기
65
A
101
41
3.14
       3.1
핵심: printf 서식 지정자에 따라 같은 값도 다르게 출력됩니다.
• %d → 10진 정수: 65
• %c → 문자: 65는 ASCII 'A'
• %o → 8진수: 65 = 1×64 + 0×8 + 1 = 101
• %x → 16진수: 65 = 4×16 + 1 = 41
• %.2f → 소수점 2자리: 3.14
• %10.1f → 전체 10칸, 소수점 1자리, 우측 정렬:        3.1
문제 7
#define 매크로 ★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

#define SQ(x) ((x) * (x))
#define ADD(a, b) a + b
#define MUL(a, b) ((a) * (b))

int main() {
    int r1 = SQ(3 + 1);
    int r2 = 10 * ADD(2, 3);
    int r3 = 10 * MUL(2, 3);

    printf("%d\n", r1);
    printf("%d\n", r2);
    printf("%d\n", r3);

    return 0;
}
정답 및 해설 보기
16
23
60
핵심: 매크로는 단순 텍스트 치환입니다. 괄호 유무가 결과를 바꿉니다.
• SQ(3+1) → ((3+1)*(3+1)) = 4*4 = 16 (괄호 있어서 정상)
• 10*ADD(2,3) → 10 * 2 + 3 = 20 + 3 = 23 (괄호 없어서 연산 우선순위 문제!)
• 10*MUL(2,3) → 10 * ((2)*(3)) = 10 * 6 = 60 (괄호 있어서 정상)
매크로 정의 시 매개변수와 전체 식을 괄호로 감싸지 않으면 연산 우선순위 오류가 발생합니다.
문제 8
2차원 배열과 포인터 ★★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};

    printf("%d\n", arr[1][2]);
    printf("%d\n", *(arr[0] + 4));
    printf("%d\n", *(*(arr + 1) + 1));

    int *p = &arr[0][0];
    printf("%d\n", *(p + 3));
    printf("%d\n", *(p + 5));

    return 0;
}
정답 및 해설 보기
6
5
5
4
6
핵심: 2차원 배열은 메모리에 행 우선으로 연속 저장됩니다: [1,2,3,4,5,6]
• arr[1][2] → 2행 3열 = 6
• *(arr[0]+4) → arr[0]은 첫 행의 시작 주소, +4하면 5번째 원소 = 5
• *(*(arr+1)+1) → *(arr[1]+1) → arr[1][1] = 5
• *(p+3) → 첫 원소부터 3칸 이동 = 4번째 원소 = 4
• *(p+5) → 첫 원소부터 5칸 이동 = 6번째 원소 = 6
2차원 배열이지만 메모리는 1차원으로 연속 배치됩니다. arr[0]+4는 행을 넘어갑니다.
문제 9
switch-case fall-through ★★☆

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    int n = 2;

    switch (n) {
        case 1:
            printf("A");
        case 2:
            printf("B");
        case 3:
            printf("C");
            break;
        case 4:
            printf("D");
        default:
            printf("E");
    }
    printf("\n");

    n = 5;
    switch (n) {
        case 1:
            printf("X");
            break;
        default:
            printf("Y");
            break;
        case 3:
            printf("Z");
    }
    printf("\n");

    return 0;
}
정답 및 해설 보기
BC
Y
핵심: break가 없으면 다음 case로 fall-through됩니다.
• n=2: case 2 매칭 → "B" 출력 → break 없으므로 case 3으로 fall-through → "C" 출력 → break 만남 → 종료
• n=5: case 1 불일치, default 매칭 → "Y" 출력 → break → 종료
default는 어디에 있든 매칭되는 case가 없을 때 실행됩니다. 반드시 마지막이 아니어도 됩니다.
문제 10
call by value vs reference ★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

void swapByValue(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

void swapByRef(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void increment(int *p) {
    (*p)++;
}

int main() {
    int x = 10, y = 20;

    swapByValue(x, y);
    printf("%d %d\n", x, y);

    swapByRef(&x, &y);
    printf("%d %d\n", x, y);

    increment(&x);
    increment(&x);
    printf("%d\n", x);

    return 0;
}
정답 및 해설 보기
10 20
20 10
22
핵심: 값에 의한 호출은 복사본을, 주소에 의한 호출은 원본을 변경합니다.
• swapByValue(x, y) → 복사본만 교환, 원본 변경 없음 → x=10, y=20
• swapByRef(&x, &y) → 주소를 전달하여 원본 교환 → x=20, y=10
• increment(&x) 2회 → x=20 → 21 → 22
C언어에는 진정한 call by reference가 없고, 포인터를 이용한 call by address로 구현합니다.
