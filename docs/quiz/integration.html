문제 1
Java · 상속+오버라이딩 ★★★

다음 Java 코드의 실행 결과를 쓰시오.

class Animal {
    String name = "Animal";
    void sound() {
        System.out.println("...");
    }
}

class Dog extends Animal {
    String name = "Dog";
    void sound() {
        System.out.println("Woof");
    }
}

class Cat extends Animal {
    String name = "Cat";
    void sound() {
        System.out.println("Meow");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal[] arr = { new Dog(), new Cat(), new Animal() };
        for (Animal a : arr) {
            System.out.print(a.name + " ");
            a.sound();
        }
    }
}
정답 및 해설 보기
Animal Woof
Animal Meow
Animal ...
핵심: 필드는 참조 타입(Animal)을 따르고, 메서드는 실제 객체 타입을 따릅니다 (동적 바인딩).
• a.name → 필드는 다형성이 적용되지 않으므로 항상 "Animal" 출력
• a.sound() → 메서드는 오버라이딩이 적용되어 실제 객체의 sound() 호출
• Dog → "Woof", Cat → "Meow", Animal → "..."
문제 2
C · 포인터 배열 ★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *p = arr;

    printf("%d\n", *p);
    printf("%d\n", *(p + 3));
    printf("%d\n", *p + 3);
    p += 2;
    printf("%d\n", *p);
    printf("%d\n", p[-1]);
    return 0;
}
정답 및 해설 보기
10
40
13
30
20
핵심: 포인터 연산에서 * (역참조)와 + (주소 이동)의 우선순위를 구분해야 합니다.
• *p → arr[0] = 10
• *(p+3) → arr[3] = 40 (괄호 안에서 먼저 주소 이동 후 역참조)
• *p+3 → arr[0]+3 = 10+3 = 13 (역참조 먼저, 그 후 덧셈)
• p+=2 후 *p → arr[2] = 30
• p[-1] → *(p-1) → arr[1] = 20

문제 8
C · 재귀함수 ★★★★

다음 C 코드의 실행 결과를 쓰시오.

#include <stdio.h>

int func(int n) {
    if (n <= 1)
        return 1;
    return n * func(n - 1) + 2;
}

int main() {
    printf("%d\n", func(4));
    return 0;
}
정답 및 해설 보기
38
핵심: 재귀 호출을 단계별로 추적합니다.
• func(1) = 1 (종료 조건)
• func(2) = 2 × func(1) + 2 = 2 × 1 + 2 = 4
• func(3) = 3 × func(2) + 2 = 3 × 4 + 2 = 14
• func(4) = 4 × func(3) + 2 = 4 × 14 + 2 = 38

public class Main {

문제 10
Python · 클래스 상속 ★★★

다음 Python 코드의 실행 결과를 쓰시오.

class Shape:
    def __init__(self):
        self.color = "red"

    def area(self):
        return 0

class Rectangle(Shape):
    def __init__(self, w, h):
        super().__init__()
        self.w = w
        self.h = h

    def area(self):
        return self.w * self.h

r = Rectangle(3, 4)
print(r.color)
print(r.area())
print(isinstance(r, Shape))
정답 및 해설 보기
red
12
True
핵심: super().__init__()으로 부모 생성자를 호출하면 부모의 속성도 초기화됩니다.
• r.color → super().__init__()에서 self.color = "red" 설정 → "red"
• r.area() → Rectangle의 area() 오버라이딩 → 3 × 4 = 12
• isinstance(r, Shape) → Rectangle은 Shape의 자식 → True

다음 빈칸에 알맞은 용어를 쓰시오.

(1) 모듈 간의 ( ________ )(은)는 낮을수록 좋고,
    모듈 내부의 ( ________ )(은)는 높을수록 좋다.

(2) 결합도의 순서를 약한 것부터 나열하면:
    자료 → ( ① ) → ( ② ) → 제어 → 외부 → 공통 → 내용

(3) 다른 모듈의 내부 기능과 자료를 직접 참조하는

정답 및 해설 보기
(1) 결합도(Coupling), 응집도(Cohesion)
(2) ① 스탬프(Stamp), ② 검인(Stamp 다음은 제어이므로 사실상 스탬프 결합도)
정답: ① 스탬프(Stamp) ② 검인(Stamp) — 자료→스탬프→제어→외부→공통→내용

• 암기법: "자스제외공내" (결합도), "우논시절통순기" (응집도)
문제 12
소프트웨어공학 · 테스트 커버리지 ★★★★

다음 코드에 대해 구문 커버리지(Statement Coverage) 100%를 달성하기 위한 최소 테스트 케이스 수와, 조건/분기 커버리지(Branch Coverage) 100%를 달성하기 위한 최소 테스트 케이스 수를 각각 쓰시오.

int check(int x, int y) {
    int result = 0;
    if (x > 0 && y > 0)
        result = x + y;
    else
        result = x - y;
    if (result > 10)
        result = 10;
    return result;
}
정답 및 해설 보기
구문 커버리지 100%: 최소 2개
분기 커버리지 100%: 최소 3개
핵심: 구문 커버리지는 모든 문장 실행, 분기 커버리지는 모든 분기(T/F)를 실행해야 합니다.
• 구문 커버리지: 모든 코드 라인을 최소 1번 실행
- TC1: x=5, y=8 → if1-T, result=13 → if2-T, result=10 (모든 구문 실행)
- TC2: x=-1, y=3 → if1-F, result=-4 → if2-F (else 구문 실행)
• 분기 커버리지: 각 조건문의 T/F를 모두 실행
- TC1: x=5, y=8 → if1-T, if2-T
- TC2: x=-1, y=3 → if1-F, if2-F
- TC3: x=3, y=2 → if1-T, result=5, if2-F (if1-T이면서 if2-F 조합)
※ 분기 커버리지는 if1의 T/F × if2의 T/F 조합을 모두 커버해야 하므로 최소 3개 필요 (2개로는 if1-T&if2-F 조합 누락 가능)

C · 비트연산 ★★★

#include <stdio.h>

int main() {
    int a = 12;  // 이진수: 1100
    int b = 10;  // 이진수: 1010

    printf("%d\n", a & b);
    printf("%d\n", a | b);
    printf("%d\n", a ^ b);
    printf("%d\n", a << 1);
    printf("%d\n", b >> 1);
    return 0;
}
정답 및 해설 보기

14
6
24
5
핵심: 비트 연산은 2진수로 변환 후 각 비트별로 연산합니다.

• a & b (AND): 1100 & 1010 = 1000 = 8

문제 19
Java · 예외처리 ★★★

다음 Java 코드의 실행 결과를 쓰시오.

public class Main {
    static int calc(int n) {
        try {
            if (n < 0)
                throw new Exception("Negative");
            return n * 2;
        } catch (Exception e) {
            System.out.print("E ");
            return -1;
        } finally {
            System.out.print("F ");
        }
    }

    public static void main(String[] args) {
        System.out.print(calc(5) + " ");
        System.out.print(calc(-3) + " ");
    }
}
정답 및 해설 보기
F 10 E F -1
핵심: finally는 return 전에 반드시 실행됩니다. print 순서에 주의!
• calc(5): n=5 ≥ 0 → return 10 전에 finally "F " 출력 → 반환값 10 출력
출력 순서: "F " → "10 "
• calc(-3): n=-3 < 0 → Exception 발생 → catch "E " 출력 → return -1 전에 finally "F " 출력 → 반환값 -1 출력
출력 순서: "E " → "F " → "-1 "
• 전체: F 10 E F -1
문제 20
소프트웨어공학 · McCabe 순환 복잡도 ★★★★

다음 제어 흐름 그래프(CFG)에서 McCabe의 순환 복잡도(Cyclomatic Complexity)를 구하시오.

제어 흐름 그래프:

    ①  →  ②  →  ③
    |      ↓      |
    |      ④      |
    |     / \     |
    |    ⑤   ⑥   |
    |     \ /     |
    |      ⑦  ←--+
    |      |
    +---→  ⑧

간선(Edge) 수: 11
노드(Node) 수: 8
연결 요소(P):  1

McCabe 순환 복잡도 공식: V(G) = E - N + 2P
정답 및 해설 보기
V(G) = 11 - 8 + 2(1) = 5
핵심: McCabe 순환 복잡도 = E(간선) - N(노드) + 2P(연결요소)
• V(G) = E - N + 2P = 11 - 8 + 2×1 = 5
• 또는 V(G) = 조건문(분기) 수 + 1로도 계산 가능 (if 4개 + 1 = 5)
• 복잡도가 10 이하이면 양호, 20 이상이면 리팩토링 권장
• 이 값은 최소 테스트 경로 수를 의미합니다
• 실기 시험에서는 그래프가 주어지고 E, N을 세어 계산하는 유형이 출제됩니다
