## 핵심 결론

**2026년 1회 정보처리기사 실기 시험은 아직 실시되지 않았습니다.**

- 원서접수: 2026년 3월 23일(월) ~ 3월 26일(목)
- 시험일: 2026년 4월 18일(토) ~ 5월 6일(수)
- 합격자 발표(1차): 2026년 6월 5일(금)
- 합격자 발표(2차): 2026년 6월 12일(금)

## 2026년 시험 주요 변경사항

- **IDE 기반 문제 도입**: 단순 코드 빈칸 채우기에서 코드 직접 작성(IDE 수준) 문제 일부 도입
- **2027년 완전 CBT 전환 예고**: 코딩 테스트 방식으로 전면 전환 예정
- 단순 문법 암기가 아닌 실무 구현 능력 평가 강화
- 출제 과목: "정보시스템 구축 실무" 단일 과목

## 출제 빈도 분석 (2024~2025 기준)

### 과목별 출제 비중
| 과목 | 코드 | 평균 출제 수 | 비율 |
|------|------|------------|------|
| 프로그래밍 (PG) | PG | 10~12문제 | 55% |
| 네트워크/보안 (NW) | NW | 3~4문제 | 18% |
| 데이터베이스 (DB) | DB | 3~4문제 | 18% |
| 소프트웨어 설계 (SE) | SE | 2~3문제 | 12% |

### 프로그래밍 언어별 출제
- Java: 4~5문제 (재귀, 상속, 인터페이스, 람다식, 참조타입)
- C: 4~5문제 (포인터, 구조체, 연결리스트, 배열, 문자열)
- Python: 1~2문제 (컬렉션, 딕셔너리, 자료구조)

### 자주 출제되는 주제 (★ = 매회 또는 거의 매회)
- ★ Java 재귀/상속/오버라이딩 추적
- ★ C 포인터/구조체/배열 추적
- ★ SQL (SELECT, INSERT, JOIN, 집계함수)
- ★ 네트워크 보안 (공격 유형: 세션하이재킹, SYN플러딩, IPSec)
- ★ CPU/프로세스 스케줄링 (SJF, SRT, RR, 대기시간 계산)
- ★ 디자인 패턴 (Adapter, Iterator, Observer 등)
- ★ 모듈 결합도/응집도 유형
- Python 자료구조 (딕셔너리, 집합, 컴프리헨션)

## 2026년 1회 추가 예상 출제 유형

1. **IDE형 코드 작성 문제** (새로 도입): 빈칸 채우기가 아닌 코드 직접 작성
2. **알고리즘 설계**: 정렬, 탐색, 재귀, 자료구조 구현
3. **SQL 작성**: SELECT + JOIN + 서브쿼리, 집계함수, DML
4. **보안**: 암호화 알고리즘(AES/RSA), 네트워크 공격 유형
5. **UML/모델링**: 클래스 다이어그램, 시퀀스 다이어그램 (최근 출제 감소)
