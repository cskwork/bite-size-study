## IP 서브넷팅 계산 (서브넷 마스크, 네트워크/호스트 주소, CIDR)

### 핵심 개념
서브넷팅은 하나의 IP 네트워크를 여러 개의 작은 네트워크로 분할하는 기술이다. CIDR(Classless Inter-Domain Routing) 표기법에서 `/n`은 네트워크 비트 수를 의미하며, 호스트 수는 `2^(32-n) - 2` 공식으로 계산한다(네트워크 주소와 브로드캐스트 주소 제외). 정보처리기사에서는 CIDR 표기 → 호스트 수 계산, 서브넷 마스크 변환이 단골 문제다.

### 키워드

- **CIDR 표기법**: `/26` → 상위 26비트가 네트워크, 하위 6비트가 호스트
- **호스트 수 공식**: `2^(32 - prefix) - 2` (네트워크·브로드캐스트 제외)
- **서브넷 마스크**: 네트워크 비트는 1, 호스트 비트는 0
- **네트워크 주소**: 호스트 비트 전부 0 (해당 서브넷의 첫 번째 주소)
- **브로드캐스트 주소**: 호스트 비트 전부 1 (해당 서브넷의 마지막 주소)
- **유효 호스트 범위**: 네트워크 주소 + 1 ~ 브로드캐스트 주소 - 1

### 자주 출제되는 CIDR 표 암기

| CIDR | 서브넷 마스크 | 호스트 수(사용 가능) |
|------|------------|-------------------|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /27 | 255.255.255.224 | 30 |
| /28 | 255.255.255.240 | 14 |
| /29 | 255.255.255.248 | 6 |
| /30 | 255.255.255.252 | 2 |

### 기출 계산 예시

**2025-2회 기출**: `223.13.234.132/26`
1. `/26` → 호스트 비트 = 32 - 26 = 6
2. 호스트 수 = 2^6 - 2 = 64 - 2 = **62**
3. 서브넷 마스크 = 255.255.255.192
4. 네트워크 주소: 223.13.234.128 (132의 하위 6비트를 0으로)
5. 브로드캐스트: 223.13.234.191

### 기출 포인트
> **2025-2회**: 223.13.234.132/26 → 호스트 수 62개 계산 직접 출제
> **2025-1회**: 브로드캐스트 도메인 개념 — 라우터가 브로드캐스트 도메인을 분리함
> **핵심 공식**: `2^n - 2` (n = 호스트 비트 수), -2는 네트워크주소·브로드캐스트 제외
> **서브넷 마스크 계산**: /26 → 11111111.11111111.11111111.11000000 → 255.255.255.192
