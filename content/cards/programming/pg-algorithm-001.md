## 정렬 알고리즘 비교 (시간복잡도)

### 핵심 개념
정렬 알고리즘은 데이터를 일정한 순서로 재배열하는 알고리즘이다. 정보처리기사에서는 각 정렬의 **동작 원리**와 **시간복잡도(최선/평균/최악)** 비교가 핵심이다. 비교 기반 정렬의 이론적 하한은 O(n log n)이며, 퀵/합병/힙 정렬이 이에 해당한다.

### 키워드
- **버블 정렬(Bubble)**: 인접 원소를 비교하여 교환. 평균/최악 O(n^2), 최선 O(n) (개선 시)
- **선택 정렬(Selection)**: 최솟값을 찾아 앞으로 이동. 모든 경우 O(n^2), 교환 횟수 최소
- **삽입 정렬(Insertion)**: 정렬된 부분에 원소를 삽입. 평균/최악 O(n^2), 최선 O(n) (거의 정렬된 데이터에 유리)
- **퀵 정렬(Quick)**: 피벗(Pivot) 기준 분할 정복. 평균 O(n log n), 최악 O(n^2). 실무에서 가장 빠른 정렬
- **합병 정렬(Merge)**: 분할 후 병합. 모든 경우 O(n log n), 안정 정렬이나 추가 메모리 O(n) 필요

### 기출 포인트
> 시간복잡도 비교표를 암기할 것: 버블/선택/삽입은 O(n^2), 퀵/합병/힙은 O(n log n)이 평균. 퀵 정렬은 **최악이 O(n^2)**인 점이 함정 출제 포인트이다. 합병 정렬은 항상 O(n log n)을 보장하는 **안정 정렬(Stable Sort)**이라는 점도 빈출. "안정 정렬"이란 동일 키의 순서가 정렬 후에도 유지되는 것을 의미한다.
