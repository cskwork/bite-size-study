## C언어 배열과 반복문

### 핵심 개념
배열(Array)은 **같은 타입의 데이터를 연속된 메모리**에 저장하는 자료구조이다. 인덱스는 0부터 시작하며, 반복문(for, while)과 결합하여 정렬, 탐색, 집계 등의 코드 추적 문제가 매회 출제된다.

### 키워드
- **배열 선언**: `int a[5]` 또는 `int a[] = {1,2,3}` (크기 자동 결정)
- **인덱스**: `a[0]`부터 `a[n-1]`까지. 범위 초과 시 정의되지 않은 동작
- **버블 정렬**: 인접 원소를 비교·교환하여 정렬. 이중 for문 패턴
- **선택 정렬**: 최솟값(최댓값)을 찾아 맨 앞(뒤)과 교환
- **교환(swap)**: `tmp = a[i]; a[i] = a[j]; a[j] = tmp;`

### 버블 정렬 트레이싱
```
원본: {3, 1, 4, 1, 5}
i=0: {1, 3, 1, 4, 5}  ← 인접 원소 비교·교환 (j=0~3)
i=1: {1, 1, 3, 4, 5}
i=2: {1, 1, 3, 4, 5}
i=3: {1, 1, 3, 4, 5}
→ a[0]=1, a[2]=3, a[4]=5
```

### 배열과 포인터 관계
```c
int a[] = {10, 20, 30, 40};
int *p = a;           // 배열명 = 첫 번째 원소의 주소
printf("%d", *(p+2)); // 30 (a[2]와 동일)
printf("%d", p[3]);   // 40 (포인터도 [] 사용 가능)
```

### 2차원 배열
```c
int a[2][3] = {{1,2,3}, {4,5,6}};
// a[행][열] 형태
printf("%d", a[1][2]); // 6
```
