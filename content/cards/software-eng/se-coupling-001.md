## 모듈 결합도 6단계

### 핵심 개념
결합도(Coupling)는 모듈 간의 상호 의존 정도를 나타내며, 낮을수록(약할수록) 좋은 설계다. 결합도가 낮으면 모듈의 독립성이 높아져 유지보수와 재사용이 용이해진다. 6단계를 강→약 순서로 암기하고 각 유형의 정의를 구별하는 것이 핵심이다.

### 키워드
- **Content(내용) 결합도** [최강]: 다른 모듈의 내부 데이터나 코드를 직접 참조·수정 — 최악의 결합
- **Common(공통) 결합도**: 두 모듈이 전역 변수(공통 데이터)를 공유 — 전역 변수 사용
- **External(외부) 결합도**: 외부에서 선언된 변수(외부 데이터 포맷, 프로토콜 등)를 공유 — 공통과 유사하나 외부 환경
- **Control(제어) 결합도**: 한 모듈이 다른 모듈의 제어 흐름(논리적 경로)을 결정하는 파라미터 전달 — 제어 플래그
- **Stamp(스탬프) 결합도**: 모듈 간에 자료 구조(레코드·배열 등)를 파라미터로 전달, 일부만 사용 — 구조체 전달
- **Data(자료) 결합도** [최약]: 모듈 간에 단순 값(스칼라) 파라미터만 전달 — 최선의 결합

### 기출 포인트
> - **강→약 순서 암기법**: "내공외제스자" (내용-공통-외부-제어-스탬프-자료)
> - **2025-1회**: 내용·스탬프·공통 결합도 정의 구분 문제 출제
> - **2024-2회**: 제어 결합도 — 제어 플래그를 파라미터로 전달하는 유형
> - "전역 변수 = 공통 결합도", "제어 플래그 파라미터 = 제어 결합도" 키워드 연결 필수
