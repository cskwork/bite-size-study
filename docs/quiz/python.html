Python 코드 실행결과 문제

정보처리기사 실기 기출 유형 — 다음 코드의 실행 결과를 쓰시오.

총 10문제
Q1
리스트 슬라이싱/메서드

다음 Python 코드의 실행 결과를 쓰시오.

a = [1, 2, 3, 4, 5]
a.append(6)
a.pop(2)
a.reverse()
print(a[1:4])
답 / 해설 보기
[5, 4, 2]
풀이:
1. a = [1, 2, 3, 4, 5] → 초기 리스트
2. a.append(6) → [1, 2, 3, 4, 5, 6]
3. a.pop(2) → 인덱스 2의 값(3) 제거 → [1, 2, 4, 5, 6]
4. a.reverse() → [6, 5, 4, 2, 1]
5. a[1:4] → 인덱스 1~3 → [5, 4, 2]
Q2
딕셔너리

다음 Python 코드의 실행 결과를 쓰시오.

d = {'a': 1, 'b': 2, 'c': 3}
d['d'] = 4
print(d.get('e', 5))
print(len(d))
print(list(d.keys()))
답 / 해설 보기
5 4 ['a', 'b', 'c', 'd']
풀이:
1. d = {'a':1, 'b':2, 'c':3} → 딕셔너리 생성
2. d['d'] = 4 → 'd' 키 추가 → {'a':1, 'b':2, 'c':3, 'd':4}
3. d.get('e', 5) → 'e' 키가 없으므로 기본값 5 출력
4. len(d) → 키 4개이므로 4
5. list(d.keys()) → ['a', 'b', 'c', 'd']
Q3
문자열 메서드

다음 Python 코드의 실행 결과를 쓰시오.

s = "Hello World Hello"
print(s.count("Hello"))
print(s.find("World"))
print(s.replace("Hello", "Hi"))
a = "a-b-c-d"
print(":".join(a.split("-")))
답 / 해설 보기
2 6 Hi World Hi a:b:c:d
풀이:
1. s.count("Hello") → "Hello"가 2번 등장 → 2
2. s.find("World") → "World"는 인덱스 6에서 시작 → 6
3. s.replace("Hello", "Hi") → 모든 "Hello"를 "Hi"로 교체 → Hi World Hi
4. a.split("-") → ['a','b','c','d'], ":".join(...) → a:b:c:d
Q4
클래스 상속/오버라이딩

다음 Python 코드의 실행 결과를 쓰시오.

class Parent:
    def show(self):
        print("Parent")

    def greet(self):
        print("Hello")

class Child(Parent):
    def show(self):
        print("Child")

c = Child()
c.show()
c.greet()
print(isinstance(c, Parent))
답 / 해설 보기
Child Hello True
풀이:
1. Child는 Parent를 상속하고 show()를 오버라이딩
2. c.show() → 오버라이딩된 Child의 show() 호출 → Child
3. c.greet() → Child에 없으므로 Parent의 greet() 호출 → Hello
4. isinstance(c, Parent) → Child는 Parent의 하위 클래스이므로 → True
Q5
lambda / map / filter

다음 Python 코드의 실행 결과를 쓰시오.

a = [1, 2, 3, 4, 5]
b = list(map(lambda x: x ** 2, a))
print(b)
c = list(filter(lambda x: x % 2 == 0, b))
print(c)
답 / 해설 보기
[1, 4, 9, 16, 25] [4, 16]
풀이:
1. map(lambda x: x**2, a) → 각 원소를 제곱 → [1, 4, 9, 16, 25]
2. filter(lambda x: x%2==0, b) → 짝수만 필터링 → 4, 16 → [4, 16]
Q6
리스트 컴프리헨션

다음 Python 코드의 실행 결과를 쓰시오.

a = [i * j for i in range(1, 4) for j in range(1, 3)]
print(a)
b = [x for x in range(10) if x % 3 == 0]
print(b)
답 / 해설 보기
[1, 2, 2, 4, 3, 6] [0, 3, 6, 9]
풀이:
1. 이중 for문: i=1,j=1→1, i=1,j=2→2, i=2,j=1→2, i=2,j=2→4, i=3,j=1→3, i=3,j=2→6 → [1, 2, 2, 4, 3, 6]
2. 0~9 중 3의 배수: 0, 3, 6, 9 → [0, 3, 6, 9]
Q7
재귀함수

다음 Python 코드의 실행 결과를 쓰시오.

def func(n):
    if n <= 1:
        return n
    return func(n - 1) + func(n - 2)

print(func(6))
답 / 해설 보기
8
풀이:
피보나치 수열 재귀 구현입니다.
func(0)=0, func(1)=1, func(2)=1, func(3)=2, func(4)=3, func(5)=5, func(6)=8
따라서 결과는 8
Q8
전역변수 / 지역변수

다음 Python 코드의 실행 결과를 쓰시오.

x = 10

def foo():
    global x
    x = 20

def bar():
    x = 30
    print(x)

foo()
print(x)
bar()
print(x)
답 / 해설 보기
20 30 20
풀이:
1. foo() 호출 → global x로 전역변수 x를 20으로 변경
2. print(x) → 전역변수 x는 20 → 20
3. bar() 호출 → 지역변수 x=30, print(x) → 30 (전역 x 영향 없음)
4. print(x) → 전역변수 x는 여전히 20 → 20
Q9
*args / **kwargs

다음 Python 코드의 실행 결과를 쓰시오.

def func(*args, **kwargs):
    print(sum(args))
    for k, v in kwargs.items():
        print(f"{k}={v}")

func(1, 2, 3, name="Kim", age=25)
답 / 해설 보기
6 name=Kim age=25
풀이:
1. *args는 위치 인자를 튜플로 받음 → (1, 2, 3)
2. sum(args) → 1+2+3 = 6
3. **kwargs는 키워드 인자를 딕셔너리로 받음 → {'name':'Kim', 'age':25}
4. items()로 순회하며 f-string 출력 → name=Kim, age=25
Q10
얕은복사 / 깊은복사

다음 Python 코드의 실행 결과를 쓰시오.

import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)
c = copy.deepcopy(a)

a[0].append(5)
a[1] = [6, 7]

print(b)
print(c)
답 / 해설 보기
[[1, 2, 5], [3, 4]] [[1, 2], [3, 4]]
풀이:
1. copy.copy(a) → 얕은복사: b는 a와 다른 리스트이지만 내부 리스트는 같은 객체를 참조
2. copy.deepcopy(a) → 깊은복사: c는 완전히 독립된 복사본
3. a[0].append(5) → a[0]은 [1,2,5]가 됨. b[0]도 같은 객체이므로 [1,2,5]로 변경됨. c[0]은 독립이라 [1,2] 유지
4. a[1] = [6,7] → a[1]을 새 객체로 교체. b[1]은 여전히 원래 [3,4]를 참조. c[1]도 [3,4]
5. b → [[1, 2, 5], [3, 4]]
6. c → [[1, 2], [3, 4]]
