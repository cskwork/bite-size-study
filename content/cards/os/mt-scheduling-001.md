## CPU 스케줄링 알고리즘 (FCFS, SJF, SRT, RR, 우선순위)

### 핵심 개념
CPU 스케줄링은 준비 큐에 있는 프로세스 중 어떤 프로세스에 CPU를 할당할지 결정하는 알고리즘이다. **선점(Preemptive)** 방식은 실행 중인 프로세스를 강제로 중단시킬 수 있고, **비선점(Non-preemptive)** 방식은 프로세스가 자발적으로 CPU를 반납할 때까지 기다린다. 평균 대기시간과 평균 반환시간 계산이 핵심 출제 포인트이다.

### 키워드

#### 핵심 용어
- **도착시간(Arrival Time)**: 프로세스가 준비 큐에 도착한 시간
- **버스트 시간(Burst Time)**: CPU를 사용하는 시간
- **완료시간(Completion Time)**: 프로세스 실행 완료 시간
- **반환시간(Turnaround Time)** = 완료시간 - 도착시간
- **대기시간(Waiting Time)** = 반환시간 - 버스트시간

#### 알고리즘 비교

| 알고리즘 | 선점/비선점 | 기준 | 특징 |
|---------|-----------|------|------|
| FCFS | 비선점 | 도착 순서 | 단순, 기아 없음, 콘보이 효과 |
| SJF | 비선점 | 짧은 버스트 우선 | 최적 평균 대기시간, 기아 가능 |
| SRT | 선점 | 남은 버스트 시간 최단 | SJF의 선점 버전 |
| RR | 선점 | 타임퀀텀 단위 순환 | 공평성, 타임퀀텀 크기가 성능 좌우 |
| 우선순위 | 선점/비선점 | 우선순위 번호 | 기아(Starvation) 문제 → 에이징(Aging)으로 해결 |

#### 계산 방법 (예시)
```
프로세스: P1(도착:0, 버스트:6), P2(도착:0, 버스트:4), P3(도착:0, 버스트:2)

FCFS 순서: P1→P2→P3
  P1 완료:6, 반환:6, 대기:0
  P2 완료:10, 반환:10, 대기:6
  P3 완료:12, 반환:12, 대기:10
  평균 대기시간 = (0+6+10)/3 = 5.33ms

SJF 순서: P3→P2→P1
  P3 완료:2, 반환:2, 대기:0
  P2 완료:6, 반환:6, 대기:2
  P1 완료:12, 반환:12, 대기:6
  평균 대기시간 = (0+2+6)/3 = 2.67ms

RR (타임퀀텀=2): P1→P2→P3→P1→P2→P1
  P3 완료:6, P2 완료:10, P1 완료:12
  평균 반환시간 = (12+10+6)/3 = 9.33ms
```

### 기출 포인트
> **2025-2회**: SJF/SRT 비교 + 라운드 로빈 타임퀀텀=3일 때 평균 반환시간 11.75ms 계산 문제 출제.
> **2025-2회**: 라운드 로빈에서 타임퀀텀이 클수록 FCFS에 가까워지고, 작을수록 문맥교환 오버헤드 증가.
> **2024-2회**: SRT 평균 대기시간 6.5ms 계산 문제 — 각 타임슬롯마다 남은 버스트시간 재계산 필수.
> 계산 문제는 **간트 차트(Gantt Chart)**를 직접 그리며 타임라인을 시각화하면 오류 방지.
