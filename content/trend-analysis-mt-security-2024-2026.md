# 정보처리기사 실기 — MT/보안 출제 트렌드 분석 (2024-2026)

> 조사 기준일: 2026-03-28
> 출처: 나무위키 출제경향, 기사퍼스트 가답안, 벨로그 기출 정리, certifykorea, procred.zeronoa.com

---

## 전체 출제 흐름 요약

- 2020년 개편 후 이론 단답형 비중 감소, 코딩 비중 증가 (50점 이상)
- MT/보안 이론은 **키워드 정의형** 단답 위주로 출제 (1-2점 문항)
- 2024-2025 기준 이론 영역에서 **기출 밖 신규 용어** 출제 빈도 증가
- 2027년부터 IDE 기반 코딩테스트로 완전 전환 예정 → 이론 파트 구조 변화 가능성

## 주제별 출제 트렌드

---

### [테스트 기법]

```
주제: 화이트박스 / 블랙박스 테스트 기법
과목: MT (애플리케이션 테스트 관리)
출제 빈도: 매회
최근 출제 회차: 2021~2025 전 회차 반복
핵심 키워드: 화이트박스, 블랙박스, 경험기반, 구문 커버리지, 결정 커버리지,
             조건 커버리지, MC/DC, 동등분할, 경계값 분석, 결정 테이블,
             상태전이, 페어와이즈, 탐색적 테스팅
카드화 우선순위: 상
```

**상세 메모**
- 화이트박스 = 구조 기반, 소스코드 참조
- 블랙박스 = 명세 기반, 입출력 중심
- 커버리지 계층 (구문 < 결정 < 조건 < 조건/결정 < MC/DC) 순서와 정의가 핵심
- 경험기반: 탐색적 테스팅, 에러추측, 체크리스트

### [테스트 커버리지]

```
주제: 테스트 커버리지 종류 및 정의
과목: MT (애플리케이션 테스트 관리)
출제 빈도: 자주
최근 출제 회차: 2022-1회, 2023-2회, 2024-1회
핵심 키워드: 구문(문장) 커버리지, 분기(결정) 커버리지, 조건 커버리지,
             조건/결정 커버리지, 변경조건/결정 커버리지(MC/DC), 다중조건 커버리지
카드화 우선순위: 상
```

**상세 메모**
- MC/DC(Modified Condition/Decision Coverage): 각 개별 조건이 다른 조건에 독립적으로 영향을 미침을 확인
- 구문=Statement, 분기=Branch/Decision, 조건=Condition

### [소프트웨어 개발 방법론]

```
주제: 애자일 방법론 (스크럼, XP, 칸반)
과목: MT (소프트웨어 개발 방법론)
출제 빈도: 자주
최근 출제 회차: 2021-1회, 2022-3회, 2023-1회, 2024-2회
핵심 키워드: 애자일 4대 가치, 스크럼(Sprint/Backlog/번다운차트),
             XP(페어프로그래밍/TDD/CI/리팩토링/공동소유),
             칸반보드, FDD, Crystal, 사용자스토리
카드화 우선순위: 상
```

**상세 메모**
- 스크럼 역할: Product Owner, Scrum Master, Development Team
- XP 핵심 실천법 5개: PP, CO, CI, 짧은 배포 주기, 단순 설계
- 애자일 4대 가치 원문 빈칸 형태로도 출제됨

### [형상관리]

```
주제: 형상관리 도구 및 개념
과목: MT (소프트웨어 개발 방법론)
출제 빈도: 가끔
최근 출제 회차: 2021-2회, 2023-3회
핵심 키워드: 형상관리, 버전관리, Git, SVN(Subversion), CVS,
             베이스라인, 형상항목, 형상감사, 형상식별, 형상통제
카드화 우선순위: 중
```

**상세 메모**
- Git vs SVN: 분산형(Git) vs 중앙집중형(SVN/CVS) 구분 출제
- 형상관리 절차: 식별 → 통제 → 감사 → 기록/보고
- 최근 시험에서 단독 출제보다 소프트웨어 생명주기/유지보수 맥락에서 출제

### [소프트웨어 품질]

```
주제: ISO 25010 / CMMI 소프트웨어 품질 모델
과목: MT (소프트웨어 품질 관리)
출제 빈도: 자주
최근 출제 회차: 2022-1회, 2023-2회, 2024-3회
핵심 키워드: ISO 25010, ISO 9126, 기능적합성, 신뢰성, 사용성,
             실행효율성, 유지보수성, 이식성, 호환성, 보안성,
             CMMI 5단계(초기/관리/정의/정량관리/최적화)
카드화 우선순위: 상
```

**상세 메모**
- ISO 9126(구) → ISO 25010(현) 관계 파악 필요
- CMMI 단계 암기: Initial → Managed → Defined → Quantitatively Managed → Optimizing
- 품질 특성 8가지 영문명+한글명 쌍으로 암기

### [보안 공격 유형]

```
주제: 웹/네트워크 보안 공격 기법
과목: 보안 (소프트웨어 개발 보안 구축)
출제 빈도: 매회
최근 출제 회차: 2021~2025 전 회차 반복 출제
핵심 키워드: SQL Injection, XSS(크로스사이트스크립팅), CSRF(크로스사이트요청위조),
             DDoS, 버퍼오버플로우, 제로데이공격, 스니핑, 스푸핑,
             피싱, 파밍, 랜섬웨어, 스캐어웨어, APT, 이블트윈,
             Watering hole
카드화 우선순위: 상
```

**상세 메모**
- SQL Injection: 입력값 미검증으로 악의적 SQL 실행
- XSS: 악성 스크립트를 웹페이지에 삽입 → 사용자 브라우저에서 실행
- CSRF: 인증된 사용자의 권한으로 위조 요청 전송
- 2024-2025 최신 트렌드: 스캐어웨어, 이블트윈, Watering hole 등 신규 용어 출제 증가

---

### [암호화]

```
주제: 암호화 알고리즘 분류 및 특성
과목: 보안 (소프트웨어 개발 보안 구축)
출제 빈도: 자주
최근 출제 회차: 2022-2회, 2023-1회, 2024-1회, 2024-3회
핵심 키워드: 대칭키(AES, DES, 3DES, SEED, ARIA, IDEA, RC4, Skipjack),
             비대칭키(RSA, ECC, ElGamal, DSA, Diffie-Hellman),
             해시함수(SHA-256, MD5, HMAC, PBKDF2),
             블록암호 운용모드(ECB/CBC/CFB/OFB/CTR),
             PKI, 전자서명, 공개키인프라
카드화 우선순위: 상
```

**상세 메모**
- 대칭키: 동일 키로 암/복호화, 빠름, 키배송 문제
- 비대칭키: 공개키/개인키 쌍, 느림, 키배송 문제 해결
- 해시: 단방향(복호화 불가), 무결성 검증
- SEED/ARIA는 국내 표준 알고리즘으로 자주 출제

---

### [접근 제어]

```
주제: 접근 제어 모델 (MAC/DAC/RBAC)
과목: 보안 (소프트웨어 개발 보안 구축)
출제 빈도: 자주
최근 출제 회차: 2021-3회, 2022-2회, 2023-3회, 2025-1회
핵심 키워드: MAC(강제적 접근제어), DAC(임의적 접근제어), RBAC(역할기반 접근제어),
             ABAC(속성기반), 보안등급, 최소권한원칙, 직무분리
카드화 우선순위: 상
```

**상세 메모**
- MAC: 시스템이 보안 레이블 기반으로 강제 통제 (군사/기밀 환경)
- DAC: 자원 소유자가 접근 권한 설정 (일반 OS 파일 권한)
- RBAC: 역할(Role) 단위로 권한 부여 → 관리 효율성 높음
- 최근 ABAC(속성기반) 출제 사례 등장

---

### [위험 분석]

```
주제: 위험 분석 기법
과목: 보안 (소프트웨어 개발 보안 구축)
출제 빈도: 가끔
최근 출제 회차: 2022-1회, 2024-2회
핵심 키워드: 위험(Risk)=자산×위협×취약점, 정량적 분석(ALE/SLE/ARO),
             정성적 분석(델파이/체크리스트/시나리오), ALE(연간기대손실),
             SLE(단일손실기대값), ARO(연간발생률), BCP, DRP
카드화 우선순위: 중
```

**상세 메모**
- ALE = SLE × ARO 공식 암기 필수
- 정량적 vs 정성적 분석 구분 문제 출제
- BCP/DRP/RPO/RTO 개념도 보안 파트에서 출제됨

---

### [클린코드 / 리팩토링]

```
주제: 클린코드, 리팩토링, 코드스멜
과목: MT (소프트웨어 유지보수)
출제 빈도: 가끔
최근 출제 회차: 2021-2회, 2023-1회
핵심 키워드: 클린코드(가독성/단순성/의존성최소화),
             리팩토링(외부동작 유지+내부구조 개선),
             코드스멜(Long Method/Large Class/Duplicate Code/Dead Code),
             기술부채, 코드품질 지표
카드화 우선순위: 중
```

**상세 메모**
- 리팩토링 목적: 기능 변경 없이 코드 내부 구조 개선
- 코드스멜 종류: Long Method, Large Class, Feature Envy, Data Clumps, Shotgun Surgery 등
- 2024년 이후 이 주제가 단독 출제보다 품질 관리 맥락에서 출제되는 경향

## 2024-2025 신규 출제 트렌드 (주의)

- **기출 밖 신규 용어 급증**: 스캐어웨어, 이블트윈, Watering hole, ISMS, TKIP, RAID 등
- 단순 암기보다 **개념 이해 기반** 서술형 답변 요구 증가
- 보안 파트에서 **네트워크 보안 프로토콜** (WPA2, SSL/TLS, IPSec) 복합 출제
- 개발방법론에서 **DevSecOps, CI/CD 파이프라인 보안** 관련 개념 등장 시작
