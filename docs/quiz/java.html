문제 1
다형성 · 상속 ★★☆

다음 Java 코드의 실행 결과를 쓰시오.

class Parent {
    String x = "Parent";
    public void show() {
        System.out.println(x);
    }
}

class Child extends Parent {
    String x = "Child";
    public void show() {
        System.out.println(x);
    }
}

public class Main {
    public static void main(String[] args) {
        Parent p = new Child();
        System.out.println(p.x);
        p.show();
    }
}
정답 및 해설 보기
Parent
Child
핵심: 필드(변수)는 참조 타입을 따르고, 메서드는 실제 객체 타입을 따릅니다.
• p.x → 필드는 다형성이 적용되지 않으므로 Parent의 x = "Parent" 출력
• p.show() → 메서드는 오버라이딩이 적용되어 Child의 show() 실행 → "Child" 출력
문제 2
String 메서드 ★☆☆

다음 Java 코드의 실행 결과를 쓰시오.

public class Main {
    public static void main(String[] args) {
        String s = "Hello World";
        System.out.println(s.charAt(6));
        System.out.println(s.substring(0, 5));
        System.out.println(s.replace("World", "Java"));
        System.out.println(s.length());
    }
}
정답 및 해설 보기
W
Hello
Hello Java
11
핵심: String 인덱스는 0부터 시작합니다.
• charAt(6) → 인덱스 6의 문자 = 'W' (공백이 인덱스 5)
• substring(0, 5) → 인덱스 0~4까지 = "Hello"
• replace("World", "Java") → "Hello Java" (원본 s는 변경되지 않음)
• length() → "Hello World"는 공백 포함 11자
문제 3
ArrayList · 컬렉션 ★★☆

다음 Java 코드의 실행 결과를 쓰시오.

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();
        list.add(10);
        list.add(20);
        list.add(30);
        list.add(1, 50);
        list.remove(2);
        for (int i = 0; i < list.size(); i++) {
            System.out.print(list.get(i) + " ");
        }
    }
}
정답 및 해설 보기
10 50 30
핵심: add(index, value)는 해당 위치에 삽입, remove(index)는 해당 위치 삭제
• add(10) → [10]
• add(20) → [10, 20]
• add(30) → [10, 20, 30]
• add(1, 50) → 인덱스 1에 50 삽입 → [10, 50, 20, 30]
• remove(2) → 인덱스 2 제거(20) → [10, 50, 30]
문제 4
try-catch-finally ★★★

다음 Java 코드의 실행 결과를 쓰시오.

public class Main {
    public static void main(String[] args) {
        System.out.print("A");
        try {
            System.out.print("B");
            int a = 10 / 0;
            System.out.print("C");
        } catch (ArithmeticException e) {
            System.out.print("D");
        } finally {
            System.out.print("E");
        }
        System.out.print("F");
    }
}
정답 및 해설 보기
ABDEF
핵심: 예외 발생 시 try 블록의 나머지는 건너뛰고, catch → finally 순서로 실행됩니다.
• "A" 출력 → try 진입 → "B" 출력
• 10/0에서 ArithmeticException 발생 → "C"는 건너뜀
• catch 블록 → "D" 출력
• finally는 항상 실행 → "E" 출력
• 예외가 처리되었으므로 프로그램 계속 → "F" 출력
문제 5
static 변수 ★★☆

다음 Java 코드의 실행 결과를 쓰시오.

class Counter {
    static int count = 0;
    int num;

    Counter() {
        count++;
        num = count;
    }
}

public class Main {
    public static void main(String[] args) {
        Counter c1 = new Counter();
        Counter c2 = new Counter();
        Counter c3 = new Counter();
        System.out.println(c1.num + " " + c2.num + " " + c3.num);
        System.out.println(Counter.count);
    }
}
정답 및 해설 보기
1 2 3
3
핵심: static 변수는 모든 인스턴스가 공유합니다.
• c1 생성: count=1, c1.num=1
• c2 생성: count=2, c2.num=2
• c3 생성: count=3, c3.num=3
• num은 인스턴스 변수이므로 각 객체가 고유 값 보유
• Counter.count는 static이므로 최종 값 3
문제 6
추상클래스 · 인터페이스 ★★★

다음 Java 코드의 실행 결과를 쓰시오.

interface Flyable {
    default void move() {
        System.out.println("Fly");
    }
}

abstract class Animal {
    abstract void sound();
    void move() {
        System.out.println("Walk");
    }
}

class Bird extends Animal implements Flyable {
    void sound() {
        System.out.println("Tweet");
    }
}

public class Main {
    public static void main(String[] args) {
        Bird b = new Bird();
        b.sound();
        b.move();
    }
}
정답 및 해설 보기
Tweet
Walk
핵심: 클래스의 메서드가 인터페이스의 default 메서드보다 우선합니다.
• b.sound() → Bird에서 구현한 추상 메서드 → "Tweet"
• b.move() → Animal 클래스의 move()와 Flyable의 default move()가 충돌
• 클래스 우선 원칙에 따라 Animal의 move() = "Walk" 실행
문제 7
생성자 체이닝 ★★★

다음 Java 코드의 실행 결과를 쓰시오.

class A {
    A() {
        System.out.print("A");
    }
    A(int x) {
        this();
        System.out.print("B");
    }
}

class B extends A {
    B() {
        super(10);
        System.out.print("C");
    }
    B(int x) {
        this();
        System.out.print("D");
    }
}

public class Main {
    public static void main(String[] args) {
        B obj = new B(5);
    }
}
정답 및 해설 보기
ABCD
핵심: this()와 super()를 통한 생성자 호출 순서를 추적합니다.
• new B(5) → B(int x) 호출
• B(int x)에서 this() → B() 호출
• B()에서 super(10) → A(int x) 호출
• A(int x)에서 this() → A() 호출
• A() → "A" 출력, A(int x) 복귀 → "B" 출력
• B() 복귀 → "C" 출력, B(int x) 복귀 → "D" 출력
• 최종: ABCD
문제 8
오버로딩 · 오버라이딩 ★★☆

다음 Java 코드의 실행 결과를 쓰시오.

class Shape {
    void draw() {
        System.out.println("Shape");
    }
    void draw(String color) {
        System.out.println("Shape:" + color);
    }
}

class Circle extends Shape {
    void draw() {
        System.out.println("Circle");
    }
}

public class Main {
    public static void main(String[] args) {
        Shape s = new Circle();
        s.draw();
        s.draw("Red");
    }
}
정답 및 해설 보기
Circle
Shape:Red
핵심: 오버라이딩(재정의)과 오버로딩(매개변수 다름)을 구분하세요.
• s.draw() → Circle이 draw()를 오버라이딩했으므로 "Circle" 출력
• s.draw("Red") → Circle에는 draw(String)이 없으므로 Shape의 오버로딩된 draw(String) 실행 → "Shape:Red"
오버로딩: 같은 이름, 다른 매개변수 / 오버라이딩: 같은 시그니처, 재정의
문제 9
형변환 · instanceof ★★★

다음 Java 코드의 실행 결과를 쓰시오.

class Animal {
    String type = "Animal";
    void info() { System.out.println("Animal"); }
}
class Dog extends Animal {
    String type = "Dog";
    void info() { System.out.println("Dog"); }
    void bark() { System.out.println("Woof"); }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        System.out.println(a instanceof Animal);
        System.out.println(a instanceof Dog);
        a.info();

        Dog d = (Dog) a;
        d.bark();
        System.out.println(d.type);
    }
}
정답 및 해설 보기
true
true
Dog
Woof
Dog
핵심: instanceof는 실제 객체 타입을 검사합니다.
• a instanceof Animal → Dog는 Animal의 자식이므로 true
• a instanceof Dog → 실제 객체가 Dog이므로 true
• a.info() → 메서드는 다형성 적용 → "Dog"
• (Dog) a → 다운캐스팅 (실제 Dog 객체이므로 안전)
• d.bark() → 다운캐스팅 후 Dog 고유 메서드 호출 가능 → "Woof"
• d.type → Dog의 필드 = "Dog"
문제 10
배열 · 반복문 ★★☆

다음 Java 코드의 실행 결과를 쓰시오.

public class Main {
    public static void main(String[] args) {
        int[][] arr = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
        int sum = 0;
        for (int i = 0; i < arr.length; i++) {
            sum += arr[i][i];
        }
        System.out.println(sum);

        for (int i = 0; i < arr.length; i++) {
            for (int j = 0; j < arr[i].length; j++) {
                if (arr[i][j] % 2 != 0)
                    System.out.print(arr[i][j] + " ");
            }
        }
    }
}
정답 및 해설 보기
15
1 3 5 7 9
핵심: 2차원 배열의 대각선 합과 조건부 출력
• 대각선 합: arr[0][0]=1 + arr[1][1]=5 + arr[2][2]=9 = 15
• 홀수 출력: 1, 3, 5, 7, 9 (% 2 != 0 조건을 만족하는 원소)
• 2차원 배열 탐색 시 행(i)과 열(j)의 인덱스 관계를 파악하는 것이 핵심
